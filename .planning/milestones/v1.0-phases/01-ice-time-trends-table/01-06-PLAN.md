## Phase Goal

ROADMAP goal (verbatim): User can scan a team's ice-time section as a trends table and immediately see which players are gaining or losing TOI and power-play time.

## Gap coverage

Closes code-review WR-03 (one failed boxscore/shift-chart request blanks the whole page and shows the raw API error). Without this, a single transient 5xx/429 on any of up to 40 requests hides the entire trends table.

<objective>
Isolate NHL request failures per game: a failed shift chart costs only that game's PP/SH, a failed boxscore costs only that game (left out and named), and when nothing can be loaded the page shows a friendly message instead of the raw API error.

Purpose: the trends table should stay usable when the NHL API has a bad moment, and never pretend a game it could not load was played (or missed) by anyone.
Output: `lib/research/team-games.ts` (allSettled, shift-chart catch, `TeamResearch.unavailableDates`), new `lib/research/team-games.test.ts`, `app/research/page.tsx` (amber note, friendly banner), the view-test fixture updated for the new field, WR-03 recorded as fixed.
</objective>
