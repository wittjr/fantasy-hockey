## Phase Goal

ROADMAP goal (verbatim): User can judge each last-game unit (EV, PP, SH; forwards and defense) by its shots, goals and shot attempts for and against, with counts that reconcile with the official boxscore. (Not in user-story form; quoted verbatim as in Phases 1 and 2.)

**Gate:** this is the plan that adds event columns to the unit tables. It depends on 03-01, 03-02 and 03-03, which together are the DATA-03 fixture gate (03-01: the regulation game and the mapper rules; 03-02: the attribution rules on every committed fixture and unit Time; 03-03: the overtime, shootout, empty-net, penalty-shot and missing-shift-chart games), and must not start until `npx tsx --test lib/research/events.test.ts lib/research/play-events.test.ts` passes on the merged branch with all three plans' tests.

**Budget note (revised 2026-10-13, twice):** the plan-checker first flagged this plan (then 03-05) at 80% of the per-plan budget. The live-data render check that used to close its Task 3 (extending `live-events-smoke.ts` to render the six tables from current NHL data and reject a negative Other count) moved to the WebKit check U3, now in plan 03-10, which loads the real page on live data, must PASS, and also rejects a negative Other count. That check verified the result of this plan's work rather than building any of it, so it no longer runs a live NHL step, has no network precondition and no 429 waits or reruns. At 70k it was still over the user's 60k cap, so its Task 3 (legend, exclusions note and amber reliability notes) moved, unchanged in content, to plan 03-08 as two tasks. This plan keeps Tasks 1 and 2 (the columns and the Other and Total rows) with every rule and test; Task 2 now also runs the full suite and build, which used to run at the end of Task 3. Estimate: about 20k fixed per plan (workflow, template, this plan, UI-SPEC and PATTERNS) plus about 22k for Task 1 and 12k for Task 2.
