## Phase Goal

ROADMAP goal (verbatim): User can judge each last-game unit (EV, PP, SH; forwards and defense) by its shots, goals and shot attempts for and against, with counts that reconcile with the official boxscore. (Not in user-story form; quoted verbatim as in Phases 1 and 2.)

<objective>
Add play-by-play to every game load and carry each game's attributed events on `ResearchGame.events` (null = unknown). A play-by-play failure keeps the game (D-05), and a live smoke proves the attributed totals reconcile with the official boxscore on current games.

Purpose: DATA-02 (unknown is null, never zeros; failures isolated) and DATA-03 on live data. This is the data the unit tables (plan 03-05) render and the throttling plan (03-06) paces.
Output: `getPlayByPlay`, `events` on ResearchGame, `events: null` in three test builders, team-games tests, and a re-runnable live smoke script.
</objective>
