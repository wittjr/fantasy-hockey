<decisions_made_in_planning>
These close points CONTEXT.md left open or that the pattern mapper raised. They are recorded so the checker and verifier can challenge them.

1. **One predicate, `creditsUnit(situation, mine, opp)` in lib/research/lines.ts, decides whether a second or an event may credit a listed unit.** It is false when either team has no goalie on ice (D-21, D-22) and, at even strength, when the skaters are not exactly 5 on 5 (D-13: 4-on-4 and 3-on-3 go to Other). attributeEvents uses it for events (this plan) and analyzeGameLines uses it for seconds (plan 03-02 Task 2), so a unit's Time and its event counts cover the same seconds. D-13 is applied to seconds as well as events because D-22 states the principle ("a unit's Time and its event counts cover the same stretches") and the approved UI-SPEC legend line 3 says Other holds "4-on-4 and 3-on-3 play". This settles research Open Question 2, which D-19 to D-23 left unanswered, in favour of the locked D-13 text. Effect: a forward trio no longer gains Time or events from 3-on-3 overtime, and a D pair no longer gains them from 4-on-4. **The user confirmed this decision on 2026-10-13: D-13 applies to Time as well as events, so 4-on-4 and 3-on-3 seconds and events go to Other through creditsUnit.**
2. **An opponent with no shift rows at a second counts as "goalie out" (pattern-mapper open point).** The fallback `{ skaters: [], goalie: false }` makes `creditsUnit` false, so those seconds and events go to Other. A second with no opposing shift rows has no trustworthy strength, so crediting it to a unit would invent unit time. Pinned by tests in plan 03-02 (events in Task 1, seconds in Task 2).
3. **Events use the union of both pulled-goalie signals.** An event goes to Other when its situationCode has a goalie digit 0 (D-21's wording) or when the shift chart shows no goalie for either team at that second (D-22's source for seconds). Where the two disagree (at most about 1% of events on the measured games), D-21's "never attributed to a listed unit" still holds.
4. **Pulled-goalie events are not an exclusion (D-21 supersedes the "empty-net" item in the carried-forward exclusions and in REQUIREMENTS UNIT-03).** The exclusion kinds are exactly shootout, penalty-shot and teammate-blocked. Plan 03-08 carries the UNIT-03 wording note.
5. **The eight fixtures are committed by three plans** (plan-checker per-plan file budget). This plan commits 2025020084, the tracer's one game, which fixes the format. Plan 03-03 commits the other five gate games and the missing-chart game 2026020026. Plan 03-04 commits the corrupted chart 2025020565 (D-23). Two test constants make the split explicit: `GATE_FIXTURES` (games whose SOG and plus-minus are reconciled) and `ALL_FIXTURES` (every committed fixture, for the accounting and listed-versus-total checks that plan 03-02 adds) both start as `[2025020084]`, and the later plans append to them.
