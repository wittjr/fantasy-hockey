## Spacing Scale

Same scale as Phases 1-2 (multiples of 4: 4, 8, 16, 24, 32, 48, 64), applied through Tailwind units. Inherited exceptions from Phases 1-2, also multiples of 4: 12px gutters (`pl-3`, `gap-3`) and 40, 48 and 56px column widths (`w-10`, `w-12`, `w-14`), listed below.

| Token | Value | Usage in this phase |
|-------|-------|---------------------|
| xs | 4px | Cell vertical padding (`py-1`), footnote line gap (`gap-1`), group-header vertical padding |
| sm | 8px | not used |
| md | 16px | not used |
| lg | 24px | Gap between the six stacked tables (`gap-6`, replaces the old grid gap-6 / lg columns) |
| xl | 32px | Page-level `gap-8` between sections (existing) |
| 2xl / 3xl | 48 / 64px | not used |

Exceptions (all intentional):
- **12px** right padding and 4px left padding on stat cells (`pl-1 pr-3`, revised 2026-10-14, G-03-3): the page already uses `pr-3` / `px-3` as its column gutter; both are multiples of 4. Right padding is what keeps right-aligned digits off the divider that follows them and shrinks the gap after a divider; left padding has no visible effect on right-aligned text, so it drops to 4px. The group header cells (`Goals`, `Shots`, `Corsi`) keep `pl-3`.
- **Section gap `gap-3`** (12px) between heading, notes and tables: existing, unchanged.
- **Hairlines**: 1px group dividers (`border-l`), 1px Total-row rule (`border-t`), row rules. Not spacing.
- **Stat column width `w-12`** (48px) on count columns and `w-14` (56px) on the SF% / CF% columns: wide enough for `100.0` and `−12` at `text-sm` plus `pl-1 pr-3` (32px and 40px of content width); multiples of 4. Time and `%` keep their existing `w-14`, `#` keeps `w-10`.

## Layout & Columns

### Section structure (replaces the `lg:grid-cols-2` grid, D-08)

**Focal point:** in each table the eye lands first on the `font-medium` Total row and the Goals / Shots / Corsi group headers, then scans up the Line column to see which unit drove the totals. The six tables share one column layout so the same column lines up down the page.

`<section className="flex flex-col gap-3">` as today:

1. `<h2 className="font-medium">` "Last game: ..." (unchanged).
2. **Amber notes that change how to read the tables** (only those that apply, in this order; each a `<p className="text-xs text-amber-600 dark:text-amber-400">`): no play-by-play for this game (D-18), shift chart looks corrupted (D-23), shift data disagrees with play-by-play (D-16). Copy in the Copywriting Contract. **(discretion)** They sit above the tables, not in the footer, because they change whether the numbers in the tables can be trusted; Phases 1-2 put amber notes in footers because those notes explain a missing square, not a doubtful number.
3. If `game.lines` is null: the existing message `No shift chart is available for this game (not published yet, or it failed to load).` and nothing else (no tables, no legend, no event notes). Unchanged.
4. Otherwise **six full-width tables stacked** in `<div className="flex flex-col gap-6">`, order **EV Forwards, EV Defense, PP Forwards, PP Defense, SH Forwards, SH Defense** (the same iteration order as today, situation then group). Each table is wrapped in `<div className="overflow-x-auto">` as a safety net on narrow laptop windows (no popover, so no clearance padding is needed).
5. **Footnotes block** under the tables: `<div className="flex flex-col gap-1 text-xs text-neutral-500">` holding, in order: the exclusions note, the legend lines, then the amber older-dates note (D-05) when it applies.

### Table anatomy

`<table className="w-full text-sm">`. 13 columns, two header rows, body rows, then Other and Total rows.

**Header row 1 (group row, D-09)** `text-xs`, no bottom border (the only header hairline is under row 2).
- First cell: `<td colSpan={4} />` (empty, covers #, Time, %, Line).
- Then three `<th scope="colgroup" colSpan={3}>` labelled `Goals`, `Shots`, `Corsi`: `border-l border-neutral-200 pl-3 pt-1 text-left text-xs font-medium text-neutral-500 dark:border-neutral-800`. Left-aligned over the group, so the label sits above the first column of the group.

**Header row 2 (column row)** `border-b border-neutral-200 text-left text-xs text-neutral-500 dark:border-neutral-800`, every `<th scope="col" className="py-1 font-medium">`:

| # | Header | Align | Width | Notes |
|---|--------|-------|-------|-------|
| 1 | `#` | left | `w-10` | existing |
| 2 | `Time` | left | `w-14` | existing |
| 3 | `%` | left | `w-14` | existing |
| 4 | table title, e.g. `EV - Forwards` | left | auto (takes the remaining width) | existing text, existing position |
| 5 | `GF` | right | `w-12` | group Goals, `border-l` + `pl-1 pr-3` |
| 6 | `GA` | right | `w-12` | `pl-1 pr-3` |
| 7 | `+/-` | right | `w-12` | `pl-1 pr-3` |
| 8 | `SF` | right | `w-12` | group Shots, `border-l` + `pl-1 pr-3` |
| 9 | `SA` | right | `w-12` | `pl-1 pr-3` |
| 10 | `SF%` | right | `w-14` | `pl-1 pr-3` |
| 11 | `CF` | right | `w-12` | group Corsi, `border-l` + `pl-1 pr-3` |
| 12 | `CA` | right | `w-12` | `pl-1 pr-3` |
| 13 | `CF%` | right | `w-14` | `pl-1 pr-3` |

Column order is exactly D-09 and the accepted preview: `# | Time | % | Line | GF GA +/- | SF SA SF% | CF CA CF%`. The `border-l` on columns 5, 8 and 11 is carried by **every** cell in those columns (header row 2, body rows, Other, Total), so the divider is continuous down the table. Headers carry `title` for mouse users (the legend repeats it for everyone): GF `Goals for`, GA `Goals against`, `+/-` `Goals for minus goals against`, SF `Shots on goal for`, SA `Shots on goal against`, SF% `Share of shots on goal`, CF `Shot attempts for`, CA `Shot attempts against`, CF% `Share of shot attempts`.

**Body rows** (listed units, capped by `UNIT_LIMITS`, D-11): existing cells for columns 1-4 unchanged (including `PlayerLink` names, separators that are an `aria-hidden` en dash span with `mx-1` and no literal spaces, wrapping after a dash allowed in column 4; unit-table names use `PendingLink`'s `overlaySpinner`, so the spinner takes no inline space). Stat cells: `py-1 pl-1 pr-3 text-right tabular-nums whitespace-nowrap`, plus the group `border-l` classes. Row rule `border-b border-neutral-100 dark:border-neutral-900` (existing).

Cell value rules (formatted by the view-model, the component only prints strings):

| Column | Value |
|--------|-------|
| GF, GA, SF, SA, CF, CA | Integer. `0` when events are known and the unit had none of that kind (a known zero). `—` only when the game's `events` is null (see States). |
| SF% | `(SF / (SF + SA) * 100).toFixed(1)`, no `%` sign (the header carries it), e.g. `62.5`. `—` when SF + SA = 0, or events null. Color `text-neutral-500` (same as the existing `%` column). |
| CF% | Same formula with CF and CA. |
| +/- | `GF − GA` through the existing `formatSignedPoints`: `+2`, `−1` (U+2212), `0`. Shows `0` when the unit had shot attempts but no goals (D-20). `—` when CF + CA = 0 (the unit had no events at all) or events null. Default text color, weight 400. |

**Other row (D-12, D-21, D-22)**, directly after the last listed unit: `border-b border-neutral-100 text-neutral-600 dark:border-neutral-900 dark:text-neutral-400`. Cell 1 empty; cell 2 Time = situation seconds minus the listed units' seconds (`formatClock`); cell 3 `%` = Other seconds / situation seconds (computed from seconds, not by subtracting rounded percentages); cell 4 text `Other`; stat cells from `total − sum(listed rows)`. Same formatting rules as body rows.

**Total row (D-12)**: `border-t border-neutral-300 font-medium dark:border-neutral-700`, last row. Cell 1 empty; cell 2 Time = the team's time in that situation; cell 3 `100.0`; cell 4 text `Total`; stat cells = the team's total for that situation. The Total row never shows `—` for Time. Percentages and +/- follow the same rules.

**Rows omitted:** when a table has no listed units, the single `None` row stays (`colSpan={13}`, `text-neutral-400`, as today). The Other and Total rows are omitted only when that situation had no time and no events (nothing to reconcile, e.g. a team with no penalty kill all game); otherwise they render even with `None` above them, so a table of all-below-cap units still reconciles.

**Forward vs defense Totals:** each event sits in exactly one forward unit and one defense pair, so the Total row of the F table and the D table for the same situation are identical. This is by design, stated in the legend, and must not be "fixed" by summing F + D.

## Interaction Contract

This phase adds **no interactive elements**. Specifically:
- No sorting, filtering, toggles, tabs, expanders or popovers on the unit tables (D-03: no refresh or cache-bypass control either).
- Header `title` attributes are the only hover affordance and carry no required information.
- Name links inside the Line column keep the Phase 2 `PlayerLink` contract exactly (UNIT-04): `sit` = the table's own situation, `aria-current` on the selected player, `title="Show who {name} plays with at {EV|PP|SH}"`. Stat cells are plain text, never links.
- Keyboard: no new tab stops beyond the existing name links.
- Cold "Last 20" loading can take about 10 seconds (D-19, accepted). **(assumption)** No new loading skeleton or `loading.tsx` is added in this phase; the existing `PendingLink` spinner on the navigation link is the only pending cue, and a warm load is instant.

## States

| State | Rule | Visual |
|-------|------|--------|
| Events available | `game.lines` and `game.events` present, match quality at or above the 95% threshold, shift chart not flagged | Full 13-column tables, Other and Total rows, exclusions note, legend. No amber note. |
| Known zero | `events` present, unit had no events of a kind | `0` in that count cell (never `—`). SF%, CF%, +/- show `—` only when their own rule above says so. |
| No play-by-play, last game (D-18) | `game.lines` present, `game.events` null | Tables keep the units with Time and `%`. Every count, SF%, CF% and +/- cell in body, Other and Total rows shows `—` (`text-neutral-400 dark:text-neutral-500`). Time and `%` in Other/Total still show real values. Amber note at the top. **No fallback to an earlier game.** Exclusions note omitted (nothing counted). Legend still shown. |
| No play-by-play, older window date (D-05) | A game earlier in the window has `lines` but no events | Nothing changes in the tables (only the last game has event columns). Amber note at the bottom of the footnotes block lists the dates. The game stays in TOI trends and the linemate strip. |
| No shift chart, last game | `game.lines` null | Existing message only; no tables, no event notes, no legend. |
| Shift data disagrees (D-16/D-17) | Match ratio under `EVENT_MATCH_THRESHOLD` (95%) | Stats still shown, amber note at the top with the rounded mismatch percentage. |
| Corrupted shift chart (D-23) | Chart flagged (foreign-team players or repeated rows beyond the fixture threshold) | Stats still shown, amber note at the top. May appear together with the D-16 note; each is its own line. |
| Pulled goalie (D-21, D-22) | Either goalie out of the net | Events and seconds fall into the situation's Other row (and Total), never a listed unit. No special visual; the legend explains it. |
| Situation with no time and no events | e.g. no penalty kill | `None` row only; no Other or Total row. |
| Unit below cap | More units than `UNIT_LIMITS` allow | Not listed; folded into Other (time and events). |
| Nothing excluded | Zero shootout and penalty-shot events | Exclusions note omitted entirely. |

## Assumptions

CONTEXT.md left these open; chosen for consistency with Phases 1-2 and recorded here so the planner and checker can challenge them.

1. **Total `%` is `100.0`** and Other `%` is computed from seconds over the situation total (same denominator as the existing unit `%` column).
2. **Percentages drop the `%` sign** in cells (header carries it), one decimal, matching the existing `%` column.
3. **Derived percent columns (SF%, CF%) use `text-neutral-500`** like the existing `%` column; counts and +/- use default foreground. No other emphasis (D-10).
4. **Amber notes that change the meaning of the numbers sit above the tables**; the older-dates note sits at the bottom with the other footnotes (Phase 1-2 placement).
5. **+/- uses the existing `formatSignedPoints`** (`+2`, `−1`, `0`) and shows `—` when CF + CA = 0 (D-20).
6. **Other and Total rows are omitted only when the situation has no time and no events.**
7. **No loading skeleton** for the cold ~10 s load (D-19 accepts it).
8. **Penalty shots are listed in the exclusions note** (research A7, resolves the CONTEXT discretion item); OT events count and the legend says so in one clause (research A8).
9. **Stat column widths** (`w-12` counts, `w-14` percentages) are sized for `100.0` and two-digit signed values; the planner may adjust by 4px multiples if real data overflows.
