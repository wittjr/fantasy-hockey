<assumption_delta_decision>
Detector: `assumption-delta scan 2` returned `detected: true` (pluralization cue "also", in SC3 "time together is also shown as a share..."). Reviewed against the actual design: the real generalization in this phase is a **second per-skater situation-seconds product** on `ResearchGame`.
- Primary noun: per-skater situation seconds. Today `lines.playerSeconds` (whole game, OT included) is the only source; this phase adds `pairs.self` (regulation only) beside it.
- Decision: **add-alongside**. Rationale: SC5 requires the Last game unit tables and Phase 1's PP/SH columns to keep their exact whole-game values, while D-19 requires regulation-only linemate time and denominators. Both products come from the one shared `bucketOnIce` + `situationFor`, so EV/PP/SH classification cannot drift.
- Accepted debt: two situation-seconds products on `ResearchGame`. What would force a promote: Phase 3's on-ice timeline for event attribution, or a decision to make Phase 1's PP/SH regulation-only. Either would promote one timeline product and derive both from it.
- Invariant test (accepted, Task 2): `pairs.self[S]` equals `analyzeGameLines`' per-skater seconds for every skater in a non-OT fixture, and is never larger with an OT shift. The tracer's live smoke asserts the same on real games.
</assumption_delta_decision>
