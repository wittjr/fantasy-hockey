# Phase 1 — UI Design Contract

> Visual and interaction contract for the "Ice-time trends" section of `/research` (the `ToiTrends` rework in `app/research/page.tsx`). Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> Brownfield: this contract matches the existing visual language of `/research` (Tailwind 4, neutral palette, `dark:` variants, `tabular-nums`, `text-sm` tables, `PendingLink`). It adds no component library and no dependency. `LastGameLines` / `UnitTable` are untouched.
>
> Sources: CONTEXT.md D-01..D-20 (locked), RESEARCH.md (CSS-only popover, pitfalls), existing `app/research/page.tsx`, `components/PendingLink.tsx`, `app/globals.css`. Items marked **(discretion)** were Claude's-discretion calls; rationale is given inline.

## Spacing Scale

Declared values (multiples of 4), applied through existing Tailwind units:

| Token | Value | Usage in this phase |
|-------|-------|---------------------|
| xs | 4px | Row vertical padding (`py-1`), header vertical padding, popover offset from strip (`mt-1`), arrow-slot gap |
| sm | 8px | Popover padding (`p-2`), gap between delta number and its arrow cluster, gap between name and DNP marker (`gap-2`) |
| md | 16px | Strip cell height (`h-4`), arrow slot width (`w-4`), gap before legend |
| lg | 24px | (unused in table; section stack uses existing `gap-3` = 12px) |
| xl | 32px | Page-level `gap-8` between sections (existing, unchanged) |
| 2xl | 48px | not used |
| 3xl | 64px | not used |

Exceptions (all intentional, none new to the page):
- **12px** column gutter (`pr-3`) and section gap (`gap-3`): already used by the existing table and section; it is a multiple of 4.
- **Strip cell: 12px wide x 16px tall, 1px gap** (`w-3 h-4 gap-px`): 12px is a multiple of 4; the 1px gap is a hairline separator, not a spacing token. 20 games = 259px, which fits inside the existing `max-w-6xl` page with horizontal scroll as the safety net.
- **Hairlines** (1px borders, 2px focus outline/outline-offset, 2px F/D divider `border-t-2`): not spacing.
- **Popover clearance 112px** (`pb-28`, see Pitfall 3 in RESEARCH): needed so a downward popover on the last row is not clipped by `overflow-x-auto`.
- **Sparkline** keeps its existing 80x20px SVG.

**Row density (discretion):** keep the existing `py-1` (4px) row padding. With the 16px strip cell, a row is ~28px tall: one line per player (CONTEXT preference), ~20 skaters fit in about 560px. The user's "numbers run together" complaint came from stacked multi-line cells, not row height, so more padding is not needed; separation comes from one-number-per-cell and right-aligned `tabular-nums` columns.

## Color

Neutral palette, matching the page. The page has no brand accent color; the only chromatic colors are semantic (green/red direction, amber caution, sky for the OT informational marker).

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `--background` `#ffffff` / `#0a0a0a` | Page and table surface |
| Secondary (30%) | `neutral-200/800` header + divider borders, `neutral-100/900` row borders, `neutral-300/700` F/D divider, `white` / `neutral-900` popover surface, `neutral-500` header text, `neutral-600` / `neutral-400` in-row muted text | Table chrome, popover, muted text |
| Accent (10%) | green `green-700` / `green-400` (up), red `red-700` / `red-400` (down); tint `green-50` / `green-950/30` and `red-50` / `red-950/30` | Directional movers only (list below) |
| Caution | `amber-600` / `amber-400` (existing "no PP/SH data" color) | Missing-shift-chart note only |
| Informational | `sky-500` (both themes) | OT marker only (strip cell ring/dashed border, sparkline OT dot) |
| Destructive | not applicable | No destructive actions in this phase |

**Accent reserved for (explicit list):**
1. The TOI Δ number when `|TOI Δ| >= 120 s` (D-18): `text-green-700 dark:text-green-400` (up) or `text-red-700 dark:text-red-400` (down), plus `font-medium`.
2. The PP share Δ number when `|PP share Δ| >= 15` percentage points (D-18): same classes.
3. The row tint (`bg-green-50 dark:bg-green-950/30` or `bg-red-50 dark:bg-red-950/30`) on `<tr>` for movers per the tint rule below.

Nothing else is green or red: not the slope arrows (always muted neutral), not sort indicators, not strip cells.

**Light-mode red is `red-700`, not the page's existing `red-600` (discretion):** `red-600` on `red-50` is about 4.4:1 and fails AA for 14px text; `red-700` is about 5.9:1. Green `green-700` on `green-50` is about 4.9:1. Dark pairs (`400` on `950/30` over `#0a0a0a`) exceed 7:1.

**Muted text on tinted rows (discretion):** in-row muted text is `text-neutral-600 dark:text-neutral-400` (not `neutral-500`) so it holds >= 4.5:1 on the `green-50`/`red-50` tint. Header text stays `text-neutral-500` as today (headers sit on the untinted surface).

**Mover rule (D-16, D-18, D-19):**
- TOI Δ "crosses" at `|Δ| >= 120 s`; PP share Δ "crosses" at `|Δ| >= 15` points. Named constants `TOI_MOVER_SECONDS = 120`, `PP_MOVER_POINTS = 15` beside the existing slope constants.
- Row tint = up if at least one delta crosses upward and none crosses downward; down if the reverse; **no tint** if one crosses up and the other down (D-19). Each crossing delta is still colored on its own.
- The delta number, not the slope, drives color (D-09).
- Never tint when the window is 1 game (D-08) or the delta is `—`.

**Color is never the only cue:**
- Every Δ carries an explicit sign (`+` or `−`) and crossing deltas are `font-medium`.
- Movers get visually hidden text in the Player cell: `<span className="sr-only">Moving up</span>` / `Moving down` (screen readers; the tint is decorative).
- OT is conveyed by outline/hollow shape, not hue alone, and by "OT" text in the popover and legend.
- DNP / excluded cells are conveyed by dashed border (shape), not color.

**Strip cell fill (not a direction cue, so neutral ink, not green/red):** fill = `bg-neutral-800 dark:bg-neutral-200` with inline `style={{ opacity }}`; `opacity = 0.2 + 0.8 * clamp((toi - avgToi + 120) / 240, 0, 1)` (+/-2:00 around the player's own average saturates). The minimum 0.2 keeps a played-but-short game visibly "filled" and distinct from a dashed DNP cell. The fill lives on an inner element so the popover child is never faded (RESEARCH "Caveat"). Shading is redundant with the popover (exact values), so it is exempt from 3:1 non-text contrast.

## Layout & Columns

Section structure (replaces the current `ToiTrends` body; same wrapper `section.flex.flex-col.gap-3`):

1. `<h2 className="font-medium">Ice-time trends</h2>`
2. Intro paragraph (`text-sm text-neutral-500`), copy in Copywriting Contract.
3. `<div className="overflow-x-auto pb-28 -mb-24">` containing the table (the negative margin cancels most of the popover clearance so no blank gap shows above the footnotes; the popover is `z-10` and paints over them).
4. Footnotes block (`text-xs text-neutral-500`, `flex flex-col gap-1`): legend, then the amber no-PP/SH note when applicable.

Table: `<table className="w-full text-sm">`, header row `border-b border-neutral-200 text-left text-xs text-neutral-500 dark:border-neutral-800` (unchanged from today), body rows `border-b border-neutral-100 dark:border-neutral-900` with the existing F/D divider (`border-t-2 border-t-neutral-300 dark:border-t-neutral-700` on the first D row). All cells `py-1 pr-3`, `whitespace-nowrap`. Forwards always precede defense regardless of sort (D-14).

Numeric columns are **right-aligned** with `tabular-nums` (discretion: aligned digits make the Avg / Δ / % columns scannable, which is the core complaint). Header `<th>` for a right-aligned column also gets `text-right`.

| # | Header | Align | Cell content | Sortable (`?sort=`) |
|---|--------|-------|--------------|--------------------|
| 1 | Player | left | Player name; if DNP last 2, a trailing marker (see States) | no |
| 2 | Pos | left | Position, then muted `text-xs tabular-nums` `{dressed}/{teamGames} GP` (e.g. `C  5/5 GP`) | no |
| 3 | Avg TOI | right | Regulation TOI average `m:ss`, `font-medium` | `avgToi` |
| 4 | TOI Δ | right | Signed delta `+1:12` / `−0:48` + arrow slot | `toiDelta` |
| 5 | PP share | right | `Math.round(ppShare)%` | `ppShare` |
| 6 | PP share Δ | right | Signed integer points `+18` / `−7` + arrow slot | `ppDelta` |
| 7 | SH | right | Average SH TOI per game `m:ss`, `text-xs` muted | no |
| 8 | Per game | left | Game strip (see Component Contract) | no |
| 9 | TOI trend | left | 80x20 sparkline | no |

Column order is exactly D-01. Old per-game numeric columns, "TOI trend" and "PP share trend" text columns (`m:ss/gm`, `pts/gm`) are removed.

**Window of 1 ("Last game", D-08):** hide columns 4, 6 and 9 (TOI Δ, PP share Δ, TOI trend); no arrows, no tint. Columns 1-3, 5, 7, 8 remain (the strip is the exact-value access, so TRND-02 still holds with one cell). Sort headers shown: Avg TOI and PP share only. If the URL carries `sort=toiDelta` or `sort=ppDelta` with `games=1`, order by `avgToi desc` and mark Avg TOI as the active sort. Windows of 3 and 5+ show everything.

**Arrow slot (D-20):** immediately after each Δ number, a fixed-width slot `<span className="ml-1 inline-block w-4 text-center text-xs text-neutral-600 dark:text-neutral-400">` holding `▲`, `▼`, or nothing. The fixed width keeps the Δ digits vertically aligned whether or not an arrow shows. The arrow is the least-squares slope direction: shown only at >= 2 included games and `|slope| >= threshold` (`TOI_TREND_THRESHOLD_SECONDS = 15` for the TOI arrow, `PP_SHARE_TREND_THRESHOLD_POINTS = 3` for the PP arrow); otherwise the slot is empty. Always neutral/muted, never green or red (D-09). Accessible text: `<span className="sr-only">trend up</span>` / `trend down` inside the slot. The number text itself is never in the slot.

## Interaction Contract

### Sorting (D-14, D-15, D-17)
- Sortable headers are `PendingLink` (existing component, `prefetch={false}`) with `scroll={false}` (the table is far down the page; without it Next scrolls to top). Header label + spinner slot inline; right-aligned headers use `justify-end`.
- Keys: `avgToi`, `toiDelta`, `ppShare`, `ppDelta`. Default state `avgToi desc` (no query params added). URL: `/research?team=MTL&games=10&sort=toiDelta&dir=asc`. `dir` omitted when `desc`; `sort` omitted when `avgToi` + `desc`. Invalid or array values fall back to default.
- Click an **inactive** sortable header: sets `desc` (biggest risers / biggest numbers first). Click the **active** header: flips direction. (discretion: fantasy use is "who is rising", so descending first.)
- Team and window links in the page header carry the current `sort`/`dir` through (extended `href()`), so switching team or window preserves the sort.
- Null values (`—`) sink to the bottom of their F/D group in both directions; ties break by `avgToi desc`. F block always before D block.
- Header affordance (discretion): no extra icon on inactive headers (keeps headers quiet). Sortable headers are links, so they get `hover:underline` and the browser focus ring; the intro paragraph states they are sortable. The **active** header is `font-medium text-neutral-900 dark:text-neutral-100` followed by `↓` (desc) or `↑` (asc) — deliberately not `▲▼`, which are reserved for the trend arrows. The active `<th>` carries `aria-sort="descending|ascending"`; others have none. `<th scope="col">` on every header.
- Non-sortable headers are plain text (`font-medium text-neutral-500`).
- Sort headers carry a `title` for mouse users (the legend repeats it for everyone): Avg TOI "Average regulation ice time per game played"; TOI Δ "Average of the team's last 2 games minus the player's earlier games in the window"; PP share "Player's share of the team's power-play time over the window"; PP share Δ "Same comparison, in percentage points".

### Per-game strip and popover (D-10, D-12, D-13, TRND-02)
- Same contract as RESEARCH Pattern 4, restated here as the visual rule: CSS-only, no client component.
- The strip `<td className="relative py-1 pr-3">` is the popover anchor; the strip itself is `<div role="group" aria-label="Per-game ice time, oldest to newest" className="flex gap-px">`.
- One cell per **team game in the window**, oldest left to newest right (same order as the sparkline). Each cell: `<span role="img" tabIndex={0} aria-label="{same text as popover, single line}" className="group/cell block h-4 w-3 ...">`. The cell itself is **not** `relative`, so the popover anchors to the `<td>`.
- Cell size 12x16px, `rounded-sm`, `outline-offset-2`; `focus-visible:outline focus-visible:outline-2 focus-visible:outline-neutral-900 dark:focus-visible:outline-neutral-100` (focus ring uses the foreground color, not sky, so it cannot be confused with the OT marker); `hover:outline hover:outline-1 hover:outline-neutral-400` as the hover cue.
- Cell states:

| State | Visual | Included in avg / delta / slope |
|-------|--------|---------------------------------|
| Played, regulation game | Solid neutral fill, opacity by TOI vs player's average (formula above) | yes |
| Played, OT game with shift data | Same fill (by regulation TOI) + `ring-1 ring-sky-500` ring | yes (regulation TOI only, D-13) |
| Played, OT game, no shift data | No fill, `border border-dashed border-sky-500` | no (excluded) |
| Did not play (not in boxscore) | No fill, `border border-dashed border-neutral-400 dark:border-neutral-600` | no (never 0) |
| Played, game has no shift chart (not OT) | Same fill as played (boxscore TOI); PP/SH shown as `—` in popover | yes for TOI; no for PP/SH (D-12) |

- Popover (`aria-hidden`, shown by `hidden group-hover/cell:block group-focus/cell:block`): `absolute left-0 top-full z-10 mt-1 w-max max-w-xs rounded-md border border-neutral-200 bg-white p-2 text-xs text-neutral-900 shadow-md dark:border-neutral-800 dark:bg-neutral-900 dark:text-neutral-100`. It opens **below** the strip, left-aligned to the strip column.
- Popover content, label/value two-column grid (`grid grid-cols-[auto_auto] gap-x-3`, labels `text-neutral-600 dark:text-neutral-400`, values `tabular-nums text-right`):
  1. Title line (`font-medium`, spans both columns): `Oct 8 vs TOR · W 3–2` (uses existing `formatDate`, `gameLabel`, `resultLabel`; omit result if not final). If OT: append ` · OT` (or ` · SO`) as a bordered `rounded border border-sky-500 px-1` tag.
  2. `TOI` `16:20`. For OT games with shift data the value is **regulation** TOI and a muted line `OT excluded` `+1:05` follows (so it reconciles with NHL.com's total). For OT games without shift data: `TOI` `—` and a muted full-width line `Excluded from averages: no shift data for overtime`; also `Total (incl. OT)` `21:05` from the boxscore.
  3. `PP` `2:10 (45% of team PP)`; `SH` `0:45`. When the game has no shift chart: both `—` plus muted full-width line `No PP/SH data (shift chart not published)`. When there was no team PP time, `PP` `0:00` and omit the percentage.
  4. DNP cell: title line plus muted full-width `Did not play`.
- The `aria-label` is the same facts as one sentence; the popover is `aria-hidden` to avoid double reading.
- Known limitations (surfaced, not hidden): see UI Considerations rows on touch and tab stops.

### Sparkline (D-11, D-13)
- Keep the existing `Sparkline` (80x20, `text-neutral-500` stroke 1.5, `aria-hidden`), now plotting **regulation** TOI. Excluded and DNP games are skipped (polyline connects played neighbours, as today).
- Last played point stays a filled dot (`r=2`). **OT games** are drawn as a hollow dot: `r=3`, `fill-background`, `stroke-sky-500`, `strokeWidth=1.5` (shape differs from a filled dot, so OT is not color-only). If the last played game is OT it is hollow instead of filled.
- Hidden for a window of 1 game; below 2 plottable points it renders the empty SVG exactly as today (keeps column width).

### Hover / focus / row behaviour
- Rows are not clickable and have no hover background in this phase (Phase 2 adds row click; do not imply clickability now).
- Player cell renders the name as plain text (no link).

## UI Considerations

Probe run 2026-10-11 after checker approval: 5 elements (E1 trends table, E2 sort header links, E3 per-game strip + popover, E4 delta cell, E5 DNP marker / footnotes), 32 applicable considerations. Element kinds confirmed complete by the user (no form, modal, or navigation). Resolved: 30 explicit, 2 backstop, 0 unresolved. Empty/error copy lives in the Copywriting Contract and States table; rows below reference it.

### Resolved (explicit)
- E1 empty: A window with games but zero skater rows renders the Copywriting Contract empty copy ("No skaters played in this window."); a team with no finished games keeps the existing page-level message.
- E1 loading: The page is server-rendered; no in-section loading state. Sort/team/window navigation shows the `PendingLink` spinner (see E2 loading).
- E1 error: The existing page-level rose error banner is unchanged; this phase adds no fetch, so the section has no error state of its own.
- E1 populated: One line per skater, forwards block then defense block with the existing F/D divider; each cell holds one value (no stacked per-game text).
- E1 partial: Games without shift charts show boxscore TOI with PP/SH "—" and an amber footnote listing those dates; an OT game without shift data is excluded from Avg/Δ/slope/sparkline but still shown (dashed sky cell) in the strip.
- E1 overflow: The table sits in `overflow-x-auto` with `whitespace-nowrap` cells; "Last 20" scrolls horizontally instead of wrapping.
- E1 zero-one-many: Window of 1 hides Δ columns, arrows, sparkline and tint and shows the "Deltas and trends need 2 or more games" note; players with 1–2 games show GP and "—" for Δ; early-season windows show only the games that exist.
- E2 loading: Each sort header is a `PendingLink` (prefetch off, `scroll={false}`) whose reserved-space spinner shows while the navigation is pending, with no layout shift.
- E2 error: An unknown, missing, or array-valued `sort`/`dir` falls back to the default sort (Avg TOI desc within F/D) with no error shown.
- E2 long-text: Header labels are fixed short strings (Avg TOI, TOI Δ, PP share, PP share Δ) plus a `↑`/`↓` glyph; `whitespace-nowrap`.
- E3 empty: A game the player missed renders an empty dashed cell; its popover/`aria-label` says the player did not play.
- E3 loading: No loading state (server-rendered; popover content is in the markup).
- E3 error: No error state; missing data is expressed as "—" fields inside the popover (see E3 partial).
- E3 populated: One 12x16 cell per team game in the window, shaded by TOI relative to the player's own window average; hover or keyboard focus shows date, opponent, TOI, PP, PP share, SH (and "OT" / "+m:ss OT excluded" for OT games).
- E3 partial: Games without shift charts keep TOI shading from the boxscore and show PP/SH "—" in the popover.
- E3 overflow: "Last 20" yields a ~259px strip inside the horizontally scrolling table; the popover is anchored to the `<td>` and opens below the strip.
- E3 zero-one-many: A 1-game window renders a single cell; cells always equal the number of team games in the window.
- E3 a11y (keyboard): Every strip cell is `tabIndex={0}` with an `aria-label` carrying the full detail text; the resulting number of tab stops (~100+ on a full roster) is accepted by the user for CSS-only detail, to be revisited with roving focus only if it proves annoying.
- E4 empty: Fewer than 3 included games, or no included game in either part, shows "—" with an empty arrow slot (States table).
- E4 loading: No loading state (server-rendered).
- E4 error: No error state; unknown values render "—", never 0:00 or 0%.
- E4 populated: Signed value (TOI as ±m:ss, PP share as ±N pts) followed by a muted slope arrow glyph; colored green/red with `font-medium` and `sr-only` "Moving up/down" when it crosses ±120 s / ±15 pts.
- E4 partial: Arrow shows at ≥2 included games while the delta still shows "—" below 3.
- E4 overflow: Values are fixed-width `tabular-nums` and right-aligned; no wrapping.
- E4 zero-one-many: Window of 1 hides the delta column entirely (D-08).
